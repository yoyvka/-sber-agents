## Конвенции для code-ассистента (MVP)

Следуй только необходимому — приоритет простоты, скорости и поддержки. Детали см. в `docs/vision.md`.

### Общие принципы
- KISS, YAGNI. Реализуй минимум для MVP; никакого оверинжиниринга.
- Малые, изолированные изменения. Предпочитай читабельность оптимизациям.
- Не вводи абстракции и слои до фактической необходимости.

### Технологический минимум
- Python 3.11; зависимости через `uv`.
- Telegram: `aiogram` v3, режим polling.
- LLM: `openai` client через OpenRouter, модель по умолчанию из конфигурации.

### Структура кода
- Используй структуру из `docs/vision.md` (`src/bot/...`). Не плодить модули.
- Вход: `main.py`. Обработчики: `handlers.py`. LLM-обёртка: `llm.py`.
- Конфиг отдельно: `config.py`. Логи — `logging.py` с базовой настройкой.

### Стиль кода
- Читаемость важнее компактности. Говорящие имена; избегай сокращений.
- Плоский контроль потока, ранние выходы вместо глубокой вложенности.
- Типы явно в публичных API; избегай `any`-подобных конструкций.
- Комментарии только по делу: неочевидные решения, инварианты, caveats.

### Ошибки и логи
- Обрабатывать предсказуемые исключения с понятным сообщением пользователю.
- Логировать ключевые события и ошибки на уровне INFO/ERROR.
- Не логировать чувствительные данные или полный текст пользовательских сообщений.

### Конфигурация
- Источник — `.env` + окружение; загрузка через `pydantic-settings`.
- Обязательные ключи валидируй на старте; при отсутствии — штатно заверши работу.

### Взаимодействие с LLM
- Формируй сообщения как `[system, ...trimmed_history, user]` с обрезкой истории до лимита.
- Параметры по умолчанию: низкая температура, ограниченный `max_tokens` и таймаут.
- Минимизируй ретраи; по сбоям — краткое сообщение пользователю и лог.

### Данные и состояние
- Без БД в MVP. История — in-memory per user с ограничением длины.
- Не сохраняй персональные данные сверх необходимого для работы сессии.

### Тестируемость и документация
- Ручная проверка ключевых сценариев (start, message, /reset, ошибки).
- Документация — только то, что нужно для запуска и поддержки (README, примеры).
